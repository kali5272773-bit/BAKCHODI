# COOKED 💀 — Advanced BKL Edition

A static, mobile-first 18+ desi roast / Truth / Dare / WYR / Confession game for GitHub Pages.

## What's new
- 22-round session instead of a tiny quiz
- Mix, Truth, Dare, WYR and Confess modes
- Chaos Mode
- Progressive roast intensity
- Session memory and contradiction-style roast triggers
- Boss rounds every 8 rounds
- Cooked / braincells / red-flag / streak meters
- Levels and achievements
- Randomized content with automatic recycling
- Share button using Web Share API
- No backend, no API key, no build process
- Responsive mobile UI

## GitHub Pages
Upload the contents of this folder to the root of a GitHub repository.
Then: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Edit content
Everything is in `data/content.js`.
Game logic is in `app.js`.
Styling is in `style.css`.

## Safety
Adult humor and profanity are used as fictional/playful roast language. Dares are designed to be voluntary and non-harmful. Don't add harassment, threats, doxxing, or dangerous dares.
